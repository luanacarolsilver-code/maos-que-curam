# Mãos que Curam — Galeria do TCC

Galeria digital do Centro Terapêutico de Artesanato para Mulheres em Tratamento Oncológico em Maringá–PR.

## Como rodar

```powershell
npm.cmd install
npm.cmd run dev
```

Abra o endereço do terminal (ex.: `http://localhost:5173`).

## Build

```powershell
npm.cmd run build
npm.cmd run preview
```
